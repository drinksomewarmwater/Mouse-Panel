V1.1.3 更新日志
  • 安装支持免交互：MP_* 环境变量可跳过对应提问，全部设好即全程不交互
  • 项目现为 hysteria2-installer 的 fork，致谢已相应调整
  • 每用户到期时间 + 同时在线 IP 限制；HY2 鉴权改用 HTTP（hy2-auth 服务）
  • HY2 端口跳跃（默认关闭，须先在云厂商防火墙放行该区间的 UDP）
  • 修用户页链接加载失败 + 节点名统一为 VPS 名-协议名
  • 用户管理加“修改权限”弹窗；到期时间改用滚轮选择器（年月日，可设为永久）
  • 滚轮选择器循环滚动（月/日/时/分/秒），年份 1900–2999 年
  • 修改权限二级弹窗关闭后菜单保留；所有弹窗统一点空白处收回
  • 添加用户改成弹窗填写（用户名、流量上限、到期时间、IP 限制），到期时间与修改权限里统一用滚轮选择器
  • 服务器设置改成一级菜单（面板名称 / 各 VPS 设置 / 添加服务器 / 流量预警设置 / 运行日志），点一项开二级弹窗，需要确认或再选的内容是三级弹窗
  • 用户列表：操作列收窄（两按钮改纵向排布），密码列与 VLESS 列取消显示；密码改在“修改权限 → 修改密码”弹窗里显示当前密码
  • 用户列表列调整：用户列改名“用户名”，新增“权限”列（管理员/用户），状态列只分正常/停用/故障；到期时间与 IP 拆成两列，管理员到期显示永久，IP 列（含管理员）沿用公用用户的格式；管理员的每月上限与本月已用也按 D1/D2 两行显示
  • 打开面板默认显示第一台 VPS 的详情（本地服务器排第一），不再恢复上次看的标签页
  • 歌词设置新增透明度调节（0–100%，越高越透明，默认 12%），只改悬浮歌词面板的背景深浅，歌词文字不受影响；滑杆轨道顶到两端，拉到 100% 不再留一截
  • 悬浮歌词去掉右侧滚动条，不可手动滚动（当前行仍自动居中滚动）
  • 修改权限新增“端口跳跃”设置：可按用户开关 HY2 端口跳跃（链接带不带 mport），默认开启；只有服务器开了跳跃区间时才生效
  • 版本更新日志列表可滚动（无滚动条），标题与关闭按钮固定不动
  • 悬浮歌词展开时显示歌曲封面（1 行时不显示）
  • 音乐歌单按用户分开：管理员与每个用户各有自己的歌单与歌曲目录；普通用户也能自己上传、删除、排序歌曲
  • 悬浮歌词展开动画改顺滑：封面改用高度+淡入过渡（不再是 display 瞬切），歌词行改用 .35s 标准缓动
  • 修歌单串号：登录时重拉歌单、打开播放列表时重拉、上传成功立即显示新歌；之前切换账号后内存里的歌单没更新，管理员会看到普通用户的歌
